# 야친자로부터 살아남기 — 서비스 소개

## 서비스명과 한 줄 소개

**야친자로부터 살아남기**

> 홈런볼 하나 권했을 뿐인데, 팀장님이 화났다.

응원팀의 최근 경기로 '야구에 진심인 사람(야친자)'의 내일 기분을 예보하고, 그 사람과 나누는 가상 대화를 미리 연습하는 웹 서비스입니다. 평범한 말이 팬심의 지뢰가 되는 순간을 볼카운트로 체험합니다.

## 타깃 사용자

주변에 KBO 열성 팬이 있지만 본인은 야구를 잘 모르는 사람입니다.

- **직장인:** 응원팀 성적에 따라 기분이 오르내리는 상사와 매일 마주치는 사람
- **친구·연인·가족:** 경기 다음 날 상대에게 말을 걸기 전에 분위기를 알고 싶은 사람
- **새로 합류한 팀원:** 야구 이야기가 오가는 자리에서 실수하지 않고 대화를 이어 가고 싶은 사람

## 해결하려는 문제

야구를 모르는 사람에게는 팬의 기분을 미리 읽을 방법도, 안전하게 말을 연습할 곳도 없습니다.

- **모르고 밟는 지뢰:** 전날 끝내기 홈런으로 진 팀의 팬에게 "홈런볼 드실래요?"처럼, 평범한 말이 패배를 떠올리게 합니다.
- **분위기를 읽기 어려움:** 연패인지, 어제 역전패를 당했는지 매일 경기를 챙겨 보기는 어렵습니다.
- **실전에서만 배움:** 실수는 실제 상사나 친구 앞에서 처음 알게 되고, 되돌리기 어렵습니다.

## 핵심 사용자 경험

상대의 내일 기분을 확인하고, 그 사람과의 대화를 실제처럼 연습한 뒤 말하기 팁을 받는 흐름입니다.

1. **상대 설정:** 관계(직장 상사 / 친구), 부르는 이름(예: 김 과장님, 민수), 응원팀을 고릅니다.
2. **내일 기분 예보:** 야구공이 베이스를 도는 로딩 뒤, "김 과장님의 내일 기분"이 야구공 표정과 최근 경기 근거로 나옵니다.
3. **대화 연습:** 상대가 먼저 "어제 경기 봤어?"라고 말을 겁니다. 상사에게는 존댓말, 친구에게는 반말로 답합니다.
4. **볼카운트:** 말할 때마다 볼 또는 스트라이크가 쌓입니다. 스트라이크 3개면 1아웃, 0아웃에서 시작해 3아웃이 되면 대화가 끝납니다.
5. **복기와 다시 하기:** 마지막 스트라이크 발언과 말하기 팁 3가지를 보고, 같은 상대와 다시 대화하거나 처음부터 다시 분석합니다.

## 주요 기능

화면은 메인 → 로딩 → 결과 → 대화 → 종료 다섯 단계입니다.

| 기능 | 내용 |
| --- | --- |
| 관계·이름·팀 입력 | 관계(직장 상사 / 친구), 부르는 이름(1~10자), KBO 10개 구단 중 응원팀 선택 |
| 분석 로딩 | 1루→2루→3루→홈으로 달리는 야구공 캐릭터가 분석 단계를 보여주고, 중간에 취소할 수 있음 |
| 내일 기분 예보 | 다섯 단계(매우 좋음~매우 안 좋음)를 야구공 표정과 애니메이션으로 표시. 예보 근거 문장을 함께 보여줌 |
| 내일의 조언 | 기분에 따라 초록·노랑·빨강으로 바뀌는 카드와 대처 요령 2가지 |
| 최근 경기 근거 | 연승·연패, 최근 승패, 평균 득점, 마지막 경기 점수, 최근 10경기 승패 칸 |
| 대화 연습 | 상대가 먼저 야구 얘기를 꺼내면, 사용자가 답하고 AI가 그 사람처럼 답장 |
| 볼카운트 판정 | 무난한 말은 볼, 위험한 말은 스트라이크. 스트라이크 3개면 1아웃, 3아웃이면 대화 종료 |
| 말하기 팁 | 3아웃으로 끝나면 마지막 스트라이크 발언과 '어떻게 말하면 좋을지' 팁 3가지 |
| 다시 하기 | 같은 상대와 다시 대화하기(볼카운트 초기화) 또는 처음부터 다시 분석하기 |

## AI 활용 방식

대화는 Claude(`claude-sonnet-5-5`)가 만들고, 기분 예보는 경기 기록과 팬 반응을 규칙·머신러닝으로 계산합니다.

**1. 대화 상대 연기와 발언 판정 (Claude)**

- 시스템 프롬프트에 상대의 이름, 응원팀, 오늘 기분과 그 이유, 현재 볼카운트를 넣습니다.
- 직장 상사는 짧고 무뚝뚝한 반말, 친구는 편한 반말로 답합니다. 기분이 나쁘고 스트라이크가 쌓일수록 더 예민하게 반응합니다.
- 팀·선수 비난, 패배 언급, 비꼬기, 관계에 안 맞는 말투는 스트라이크, 그 외는 볼로 판정합니다.
- 답장과 판정은 `respond` 도구(strict JSON 스키마)로 받아 서버에서 검증합니다.
- 볼카운트와 아웃·종료 계산은 AI가 아니라 코드가 합니다.
- 3아웃이면 대화 전체를 보내 `tips` 도구로 말하기 팁 3개를 받습니다.

**2. 내일 기분 예측 (규칙 + 머신러닝)**

- 최근 경기 승패·득실점·연승연패와 커뮤니티 게시글의 긍정·부정 비율을 점수(-100~100)로 합산해 다섯 단계로 나눕니다.
- 게시글 감성은 한국어 사전·규칙으로 분류하며, AI API를 쓰지 않습니다.
- 이용자 기분 기록이 쌓이면 Python·NumPy로 학습한 다중 클래스 로지스틱 회귀 모델을 적용하도록 설계되어 있습니다.

**3. 실패 대비**

- Claude 호출이 실패하거나 10초를 넘기면 위험 단어 목록으로 판정하고 기본 답장·기본 팁으로 응답해 화면이 깨지지 않습니다.
- 경기 자료가 없는 팀은 다른 팀 샘플 대신 "보통" 기본 예보를 보여줍니다.

현재 경기·게시글 자료와 학습 모델은 시연용 샘플이며, 화면에도 샘플임을 표시합니다.

## 기술 스택과 인프라

Next.js 하나로 화면과 서버 API를 함께 만들고 Vercel에 배포합니다.

| 영역 | 사용 기술 |
| --- | --- |
| 프론트엔드 | Next.js 16.4 (App Router, Turbopack), React 19.3, TypeScript 5, Tailwind CSS 4, SVG 애니메이션 |
| 서버 API | Next.js Route Handler: `/api/forecast`(기분 예보), `/api/chat`(대화 한 턴), `/api/daily-mood`(경기·기분 조회) |
| AI | Anthropic Claude API (`@anthropic-ai/sdk`, 모델 `claude-sonnet-5-5`), 도구 호출로 구조화 응답, 10초 타임아웃 |
| 데이터 분석 | Python 3.11 + NumPy (게시글 수집·감성 분류·로지스틱 회귀 학습), TypeScript 스냅샷 생성 스크립트 |
| 경기 자료 | KBO 웹 응답 또는 API-SPORTS(선택), CSV 입력 |
| 상태 관리 | 서버는 대화를 저장하지 않음. 입력값은 브라우저 탭의 sessionStorage, 대화·볼카운트는 매 요청마다 브라우저가 전송 |
| 배포·운영 | Vercel (`main` 브랜치 운영 자동 배포, 그 외 브랜치는 미리보기), 비밀 환경 변수로 API 키 관리 |
| 자동화 | GitHub Actions: 매일 09:00(KST) 커뮤니티 반응 수집·집계 스냅샷 갱신 워크플로 |
| 품질 | ESLint, Node 테스트 러너(분석·로딩 84개), Python unittest, 대화 볼카운트 셀프테스트 |

API 키는 서버 전용 파일(`import "server-only"`)에서만 읽고 브라우저에 노출하지 않습니다.
