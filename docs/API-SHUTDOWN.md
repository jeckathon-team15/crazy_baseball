# 해커톤 종료 및 AI API 중단 기록

- 처리일: 2026-11-14 (한국 시간)
- 요청: 행사 종료에 따라 API 사용 중단 및 GitHub 기록 보관.

## 완료한 조치

1. Anthropic Console에서 시연 전용 API 키를 비활성화했습니다. 완료 알림과 메뉴의 ‘API 키 다시 활성화’를 확인했습니다. 기존 배포본에 남은 동일 키도 더 이상 인증에 사용할 수 없습니다.
2. `lib/config.ts`의 `AI_SERVICE_ENABLED`를 `false`로 설정했습니다.
3. `/api/chat`은 대화 전송과 수동 종료 분석 모두 HTTP 410 및 종료 안내를 반환합니다. Claude 호출 전에 차단합니다.
4. 공통 Claude 호출 함수에도 같은 차단을 넣어 직접 호출 경로에서 유료 요청이 발생하지 않도록 했습니다.
5. 화면·경기 조회·테스트 샘플·소스 코드는 보관합니다. Claude 대화와 AI 복기는 중단 상태입니다.

## 최종 구현 기록

- 명칭: 야친자 경보기. Next.js 웹 서비스, main 브랜치의 Vercel 운영 배포.
- 시연 기준: 2026-10-07 상황, 2026-10-06 경기 조회.
- 첫 화면: 야구장 사진 배경, 구단 선택, 관계·부르는 이름 설정, 극대노 샘플 테스트.
- 분석된 기분 5단계에 따른 야구공 캐릭터 및 상사/친구별 첫 대사.
- 대화 카운트: 0아웃 시작, 3아웃 종료. 수동 종료도 지원.
- 종료 전에는 실제 대화 기반 Claude 팁·복기와 대화 내역 표시를 확인했습니다.
- 제목 클릭 시 홈 이동, 시연 날짜 안내와 사진 CC BY-SA 4.0 출처 유지.

## 운영 참고

- 키 자체를 삭제하지 않고 비활성화했습니다. Vercel의 기존 환경 변수 값은 남아 있을 수 있지만 해당 키는 비활성 상태입니다. 키 원문은 이 저장소에 기록하지 않습니다.
- 재개 시에는 관리자가 유효한 서버용 API 키를 별도로 설정하고 코드의 중단 스위치를 명시적으로 변경한 후 배포해야 합니다. 자동 재개되지 않습니다.
- 비활성화 전 발생한 사용량은 청구 화면에 나중에 반영될 수 있습니다.
